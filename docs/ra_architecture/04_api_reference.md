# Phase 4: API Reference

The CLI scripts, Temporal client functions, Pydantic models, and environment variables of [`biosciences-temporal`](../../README.md).

The machine-readable contract is [`docs/inspect.json`](../inspect.json), generated by [`scripts/document_architecture.py`](../../scripts/document_architecture.py).

---

## 1. CLI scripts ([`scripts/`](../../src/biosciences_temporal/scripts/))

| Script | Command | Options | Description |
| :--- | :--- | :--- | :--- |
| `run_agent` | `uv run python -m src.biosciences_temporal.scripts.run_agent` | `--gene-a` (default `"TP53"`), `--gene-b` (default `"TYMS"`), `--output` / `-o` | Runs [`CQ14Orchestrator`](../../src/biosciences_temporal/agents/cq14.py) standalone without Temporal |
| `run_worker` | `uv run python -m src.biosciences_temporal.scripts.run_worker` | none | Loads `.env` (`override=True`), configures Logfire, and runs [`worker.py`](../../src/biosciences_temporal/temporal/worker.py) `main` on `biosciences-task-queue` |
| `run_workflow` | `uv run python -m src.biosciences_temporal.scripts.run_workflow` | `--gene-a`, `--gene-b`, `--target-name`, `--condition`, `-w` / `--workflow-id`, `--no-wait` | Starts a new `CQ14Workflow` or resumes an existing workflow ID via [`client.py`](../../src/biosciences_temporal/temporal/client.py) |
| `query_logfire` | `uv run python -m src.biosciences_temporal.scripts.query_logfire` | `--limit` / `-n` (default `10`), `--sql`, `--type` (`recent` \| `llm` \| `agent`), `--format` (`json` \| `table`) | Queries Logfire traces via `LogfireQueryClient` using `LOGFIRE_READ_TOKEN` |

## 2. Temporal client functions ([`client.py`](../../src/biosciences_temporal/temporal/client.py))

| Function | Signature | Description |
| :--- | :--- | :--- |
| `start_workflow` | `(gene_a="TP53", gene_b="TYMS", target_name="thymidylate synthase", condition="cancer", workflow_id=None) -> str` | Connects to `localhost:7233`, generates `cq14-<gene_a>-<gene_b>-<8hex>` if `workflow_id` is `None`, starts `CQ14Workflow.run` on `biosciences-task-queue`, and returns `workflow_id` |
| `get_result` | `(workflow_id: str) -> str` | Connects to `localhost:7233` and awaits `client.get_workflow_handle(workflow_id).result()` |
| `run_and_wait` | `(gene_a="TP53", gene_b="TYMS", target_name="thymidylate synthase", condition="cancer") -> str` | Calls `start_workflow` followed by `get_result` |

## 3. Environment variables ([`base.py`](../../src/biosciences_temporal/agents/base.py))

| Variable | Default / Resolution | Purpose |
| :--- | :--- | :--- |
| `OPENROUTER_API_KEY` | Required for live runs (falls back to `TestModel` if unset) | Authenticates `OpenRouterModel` against OpenRouter free-tier endpoints |
| `OPENROUTER_FREE_MODEL` | `nvidia/nemotron-3.5-lightning:free` | Primary free-tier model supporting native tool calling and structured Pydantic output |
| `OPENROUTER_FALLBACK_MODEL` | `openrouter/free` | Secondary free-tier model wrapped in `FallbackModel` |
| `TYPESAFE_API_KEY` | Optional | Authenticates direct `TypeSafeModel` (`jev-latest`) decision triage when `typesafe-sdk` is installed |
| `USE_TEST_MODEL` | `false` | Forces `create_model()` to return deterministic `TestModel()` |
| `BIOSCIENCES_MCP_PATH` | `../biosciences-mcp` (sibling repo fallback in `_find_sibling_repo`) | Path to the `biosciences-mcp` repository used as `cwd` for `MCPServerStdio` |
| `BIOGRID_API_KEY` | Passed via `os.environ.copy()` to `MCPServerStdio` | Required by `biosciences-mcp` for BioGRID genetic interaction queries |
| `NCBI_API_KEY` | Optional (passed to `MCPServerStdio`) | Increases NCBI rate limits inside `biosciences-mcp` |
| `LOGFIRE_TOKEN` | Optional | Logfire write token configured in `run_agent.py`, `run_worker.py`, and `run_workflow.py` |
| `LOGFIRE_READ_TOKEN` | Required for `query_logfire` | Logfire read token used by `LogfireQueryClient` |

## 4. Configuring & changing models (worker-wide vs. individual activity)

Model resolution in [`base.py`](../../src/biosciences_temporal/agents/base.py) (`create_model(model_name=MODEL, *, agent_name=self.name)`) supports three levels of configuration:

| Scope | How to Configure | Example |
| :--- | :--- | :--- |
| **1. Worker-Wide Default (`.env`)** | Set `OPENROUTER_FREE_MODEL` and `OPENROUTER_FALLBACK_MODEL` in `.env` (matching `news-agent-temporal/.env.example`) | `OPENROUTER_FREE_MODEL=nvidia/nemotron-3.5-lightning:free`<br/>`OPENROUTER_FALLBACK_MODEL=openrouter/free` |
| **2. Individual Activity / Agent via `.env`** | Set `BIOSCIENCES_MODEL_<AGENT_NAME_UPPER>` in `.env` for any of the 9 `AgentRunner` names (`ANCHOR_RESOLVE`, `ENRICH_PROTEIN`, `EXPAND_INTERACTIONS`, `TRAVERSE_DRUGS`, `TRAVERSE_TRIALS`, `VALIDATE_GENE`, `VALIDATE_DRUG`, `VALIDATE_TRIAL`, `VALIDATE_SL`) | `BIOSCIENCES_MODEL_VALIDATE_SL=nvidia/nemotron-3.5-lightning:free` |
| **3. Individual Activity / Agent in Code** | Pass `model=create_model("...")` (or a `Model` / `FallbackModel` instance) to `AgentRunner(..., model=...)` in `resolve.py`, `enrich.py`, `expand.py`, `drugs.py`, `trials.py`, or `validate.py` | `_runner = AgentRunner(..., model=create_model("nvidia/nemotron-3.5-lightning:free"))` |
